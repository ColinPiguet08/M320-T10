# Project description:

In this project, we're creating a customizable basketball player using Java. Inspired by games like NBA 2K, players can build their own player’s skills and attributes. We’re still deciding if this project will be a console-only game or a full app, but either way, it will offer a fun way to create and develop a unique basketball Player.
